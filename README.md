# Hệ Thống Điểm Danh Nhận Diện Khuôn Mặt & Quản Lý Học Tập

## 1. Tổng quan

Face Attendance Learning System là hệ thống hỗ trợ quản lý học tập kết hợp điểm danh tự động bằng công nghệ nhận diện khuôn mặt. Hệ thống giúp tự động hóa quy trình điểm danh, quản lý bài tập, bài kiểm tra và theo dõi kết quả học tập.

---

## 2. Vấn đề

Các hệ thống quản lý học tập truyền thống gặp nhiều hạn chế:

* Điểm danh thủ công mất thời gian
* Dễ xảy ra gian lận (điểm danh hộ)
* Khó quản lý tập trung bài tập, kiểm tra và điểm số
* Thiếu tính tự động và trải nghiệm người dùng chưa tốt

---

## 3. Giải pháp

Hệ thống cung cấp:

* Điểm danh tự động bằng nhận diện khuôn mặt
* Quản lý bài tập, bài kiểm tra và điểm số
* Hệ thống web và mobile hỗ trợ người dùng mọi lúc
* Chatbot AI hỗ trợ tra cứu thông tin học tập

---

## 4. Tính năng chính

* Điểm danh bằng nhận diện khuôn mặt
* Quản lý sinh viên, lớp học
* Quản lý bài tập và bài kiểm tra
* Theo dõi và thống kê điểm số
* Chatbot AI hỗ trợ hỏi đáp
* Đồng bộ dữ liệu giữa web và mobile

---

## 5. Kiến trúc hệ thống

Hệ thống gồm 3 thành phần chính:

### Backend

* RESTful API xây dựng bằng Node.js
* Xử lý logic nghiệp vụ và quản lý dữ liệu

### Frontend

* Web app cho admin/giảng viên (React)
* Mobile app cho sinh viên (Flutter)

### AI & Computer Vision

* Nhận diện khuôn mặt bằng ML Kit và OpenCV
* Chatbot AI hỗ trợ người dùng

---

## 6. Công nghệ sử dụng

* Backend: Node.js, Express
* Frontend: React
* Mobile: Flutter
* AI/ML: Google ML Kit, OpenCV
* Database: MySQL

---

## 7. Hướng phát triển

* Cải thiện độ chính xác nhận diện khuôn mặt
* Tích hợp thông báo real-time
* Thêm phân tích dữ liệu học tập
* Tối ưu hiệu năng hệ thống

---

## 8. Kết luận

Dự án thể hiện khả năng xây dựng hệ thống full-stack kết hợp AI và Computer Vision, giải quyết bài toán thực tế trong giáo dục và quản lý học tập.
